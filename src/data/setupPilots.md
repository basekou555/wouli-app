## 🛠️ Procédure de Création

### Étape 1: Créer les Comptes Business
1. Aller sur `/business/signup`
2. Pour chaque établissement, remplir le formulaire avec les données ci-dessus
3. Valider la création du compte
4. Répéter pour les 8 établissements

### Étape 2: Créer les Événements
Une fois connecté dans chaque dashboard business, créer 5-6 événements par établissement.

**Exemples d'événements par catégorie:**

#### Restaurants (a-manger, a-boire)
- Dîners à thème
- Brunchs weekend
- Soirées cocktails
- Masterclass culinaires

#### Bars (a-boire, soirees)
- Happy hours
- Concerts live
- Soirées DJ
- Quiz culturels

#### Clubs (soirees)
- Soirées électroniques
- Concerts hip-hop
- Events thématiques
- Nuits underground

#### Activités (activites)
- Initiations
- Team buildings
- Anniversaires
- Événements familiaux

### Étape 3: Tests de Validation

#### Test Interface User (/app)
- Vérifier l'affichage des événements dans le swipe
- Tester les filtres par catégorie
- Valider les interactions (likes, participations)

#### Test Interface Business (/business)
- Dashboard avec statistiques
- Création/modification d'événements
- Analytics et performance

#### Test Intégrations
- Redirection après connexion
- Gestion des profils
- Cohérence des données

## 📊 Résultat Attendu

## 🎯 Prêt pour les Pilotes

Une fois cette procédure terminée, vous disposerez d'une base de données réaliste pour présenter Wouli à vos établissements pilotes et démontrer la valeur du produit.

Les pilotes pourront :
- Tester l'interface business complète
- Voir leurs événements dans l'app user
- Analyser les statistiques en temps réel
- Comprendre l'impact marketing de Wouli
